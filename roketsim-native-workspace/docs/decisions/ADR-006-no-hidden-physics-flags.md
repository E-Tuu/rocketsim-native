# ADR-006 No Hidden Physics Flags

## Karar

Fizik davranışı gizli feature flag veya environment variable ile değiştirilmeyecektir.

## Gerekçe

Aynı girdinin hangi fizik modelini çalıştırdığı açıkça izlenebilir olmalıdır.

## Sonuçlar

Gelecekteki model veya profil seçimleri sürümlenmiş, doğrulanan ve provenance kaydı taşıyan açık girdiler olacaktır.
