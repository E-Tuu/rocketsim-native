# ADR-004 No Runtime AI in Physics

## Karar

Runtime physics path içinde AI, LLM veya harici AI API çağrısı bulunmayacaktır.

## Gerekçe

Fizik yürütmesinin deterministik, test edilebilir ve yeniden üretilebilir olması gerekir.

## Sonuçlar

AI tabanlı davranış fizik sonucu üretme veya değiştirme yoluna eklenmeyecektir.
